# Landy 마케팅팀 공유 자료

2026-10-03 기준 PRD와 유저 플로우를 제품 가치·사용자 행동·안내 콘텐츠 중심으로 편집한 A4 PDF다.

- [제품 요구사항 · PRD (10쪽)](./Landy-PRD-Marketing.pdf): 제품 정의, 사용자 가설, 핵심 경험, 기능 요구사항 37개, 품질 기준 8개, 성공 지표 제안, 홍보 표현, 미결정 사항.
- [유저 플로우 (13쪽)](./Landy-User-Flows-Marketing.pdf): 전체 여정, 17개 과업, 흐름 도식, 예외/복구, 안내·콘텐츠 포인트, 운영과 조건부 AI 경험.

현재 구현과 보완 대상, 운영 설정에 따른 조건부 제공, 검증 전 제품·마케팅 제안을 구분했다. 성과 수치나 사용자 조사를 새로 확인한 자료가 아니며, 도식은 경험 설명용으로 실제 앱 캡처가 아니다.

- [인스타그램 소개 시리즈](./instagram/README.md): 연결 표지 3개, 게시물별 5장 PDF, 업로드용 PNG와 캡션.

마케팅팀이 보기 쉽도록 상세 코드 경로와 기술 수용 기준은 원문에 남겼다. 상세 내용은 [PRD](../PRD.md), [유저 플로우](../USER-FLOWS.md), [종합 검토](../PROJECT-REVIEW-2026-10-03.md)를 우선한다. PDF의 홍보 문구는 검토용 초안이다.

## 다시 생성하기

프로젝트 의존성을 설치한 환경에서 로컬 Chrome 또는 Edge를 사용한다. 별도 외부 요청이나 운영 DB 접근은 하지 않는다.

```powershell
node scripts/generate-marketing-pdfs.mjs
```

브라우저를 자동으로 찾지 못하면 `LANDY_PDF_BROWSER` 환경 변수에 실행 파일 경로를 지정한다. 스크립트는 로컬 Wanted Sans를 PDF에 포함하고, 37개 FR/8개 NFR/17개 UF의 범위, 페이지 넘침과 PDF 페이지 수를 검사한다. 편집 HTML·검증 결과·페이지 미리보기는 실행 결과에 표시되는 OS 임시 폴더에 저장된다.

기능 목록은 원문 PRD에서 가져오며, 나머지 설명과 여정 요약은 생성 스크립트의 편집 내용이다. 원문 변경 시 내용 정합성과 실제 운영 설정을 검토한 뒤 다시 생성한다.
